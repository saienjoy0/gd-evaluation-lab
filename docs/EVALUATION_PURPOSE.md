# GD評価の目的と非目的

## 1. 目的

GD Evaluation Labは、GD APP内で観察された**セッション中の行動**を、再現可能・説明可能・検証可能な形で評価するための研究基盤である。

v0.1の目的は次の三つに限定する。

1. 利用者へ、良かった行動・根拠発言・次回の改善行動を返す。
2. AI参加者とGDシステムが、利用者に公平な評価機会を提供したか検査する。
3. ルーブリック、シナリオ、モデル、プロンプト、評価器の版を保存し、同じログを再採点できるようにする。

## 2. 非目的

v0.1では次を行わない。

- 採用合否の自動決定
- 将来業績の予測
- 人格、外向性、リーダー適性などの固定的推定
- 声の高さ、アクセント、方言、性別らしさ、年齢らしさ、表情、視線による能力判定
- 1回のGDだけを根拠とした恒久的な人物評価
- 企業別の合格ラインや職種別の最終配点
- 根拠発言のないスコア提示

## 3. 評価単位

評価単位は人物ではなく、**特定のシナリオ・特定のセッションで観察された行動**である。

推奨表現:

> 今回のセッションでは、他者の懸念を要約して提案条件へ反映する行動が確認されました。

禁止表現:

> あなたは協調性が高い人です。

## 4. 基本原則

- 観察可能な行動だけを評価する。
- AI側の品質と利用者の能力を分離する。
- 低い発言量を直ちに低能力とみなさない。
- 評価機会が不足した場合は低得点ではなく`NE`とする。
- 各評価には実在する`message_id`を証拠として付ける。
- 4点には原則として複数の独立した証拠を要求する。
- 不確実な評価は`confidence`を下げ、人間レビュー対象にできるようにする。
- 実名、メールアドレス、生音声、未匿名化ログをこのリポジトリへ保存しない。

## 5. 公開段階

### v0.x

練習・研究・改善フィードバック用。旧評価とshadow modeで比較する。

### v1.0候補

人間二重評価、再採点安定性、公平性、根拠整合性を検証した後にのみ昇格を検討する。
